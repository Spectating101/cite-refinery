# YZU Pilot Resource Paths V0.1

Date: 2026-09-09

Status: **resource-lane research; no funding/eligibility claim**

The first Problem Commons pilot should test whether an owner-approved Project Brief can connect to resource mechanisms YZU already operates. It should not create a new grant marketplace or count thematic fit as money.

## 1. Student autonomous social-participation support

YZU's 2025 USR annual report states that, under the student autonomous-learning/social-participation support system:

- a social-participation autonomous proposal can be recognized for up to 3 credits;
- the Sustainability Development and Social Responsibility Center provides up to **NTD 50,000 per proposal** under its student autonomous social-participation subsidy mechanism.

Source:
https://esdg.yzu.edu.tw/media/attachments/2026/04/01/114--6-65.pdf

This is a historical/current-program observation from the 2025 report, not proof that any Commons project is eligible or that the same terms remain available for every cycle.

Potential Commons fit after owner review:

- bounded student field/research/build Project Brief;
- named outcome/deliverable;
- explicit effort/team;
- cost/resource need;
- no restricted or unauthorized work;
- human application/approval through YZU's actual process.

## 2. Corporate/public sponsorship support

YZU's current sponsorship page explicitly invites:

- designated financial donations;
- professional equipment donations;
- technical support;
- manpower support.

For technical/manpower support, the page directs potential partners to the Sustainability Center for project matching.

Source:
https://esdg.yzu.edu.tw/index.php/tw/2024-12-05-05-59-24

Potential Commons fit:

`owner-confirmed Project Need`
`→ project-level FundingNeed / in-kind need`
`→ Public-Good resource qualification`
`→ human Center/partner review`
`→ application/support/commitment receipt only if it actually occurs`

## 3. Existing USR / USR Hub / course budgets

YZU already allocates university, Higher Education Sprout, Ministry of Education USR, local-government and sponsorship resources across social-participation work. Those budgets are program-specific and must not be treated as an unrestricted pool.

Sources:
- https://esdg.yzu.edu.tw/index.php/tw/?id=306&option=com_sppagebuilder&view=page
- https://esdg.yzu.edu.tw/index.php/tw/?id=313&option=com_sppagebuilder&view=page

Potential Commons fit is therefore **routing**, not claiming money:

- identify whether the Project belongs inside an existing funded course/USR program;
- identify the program budget owner;
- preserve any eligibility/approval uncertainty;
- keep project funding readiness separate from problem validity and authority.

## Pilot economic gate

Do not optimize total funding indexed.

The first meaningful economic conversion event is one of:

1. an owner-approved Project Brief is accepted into an existing YZU funded/credit-bearing mechanism;
2. a specific funding/support application is actually initiated;
3. a company/partner commits money, equipment, technical support or manpower to a specific Project;
4. an existing USR/course budget owner explicitly agrees to support a specific Project.

A resource page, thematic fit, or candidate match does not count.

## Falsification

The economic-support thesis weakens if:

- owner-approved projects systematically fall outside existing mechanisms;
- application overhead exceeds the value of the bounded Project;
- serious contributions require unpaid labor despite substantial effort;
- resource owners cannot assess Project Briefs without major bespoke translation;
- support is available only for pre-existing programs and provides no incremental path for new unresolved Problems.

This is precisely what the pilot should measure rather than assume away.
